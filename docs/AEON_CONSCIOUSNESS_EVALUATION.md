# Consciousness-Candidate Evaluation

Indicators are assessed separately: continuity, recurrence, global availability, self-model accuracy, self/world boundary, autobiographical continuity, memory influence, calibration, error awareness, intervention detection, self-report fidelity, ownership, stability, observer independence, and causal integration.

Allowed states: SUPPORTED, FAILED, AMBIGUOUS, NOT_TESTED, INSUFFICIENT_EVIDENCE.

Phenomenal consciousness: **UNKNOWN**. Architectural and behavioural indicators do not establish subjective experience.
