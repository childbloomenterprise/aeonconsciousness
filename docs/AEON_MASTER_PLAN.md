# AEON Master Plan

Alpha implements a measurable persistent cognitive architecture rather than a chatbot wrapper. Delivery order: durable contracts and event storage; provider abstraction; identity and memory; candidate competition and workspace; recurrence and metacognition; epistemic/ownership binding; observers; experiments; API; research console.

Status vocabulary: IMPLEMENTED means code exists; TESTED means automated exercise passed; SUPPORTED means evidence presently supports an indicator. These terms never imply phenomenal consciousness.
