# AEON 0.3 release evidence — 2026-10-03

## What ships

- Installable universal Python wheel and source distribution, MIT project license
  plus retained upstream notices. Command `aeon`, import `aeon_worker`.
- Public AEONWorker SDK, structured AgentRequest/ModelReply contract, validated
  CallbackAdapter and explicit CLI module:factory loading.
- Existing NVIDIA/Gemini routing, optional Codex inference and native NVIDIA
  NeMo Agent Toolkit integration remain available.
- Budget reservations apply to external adapters supporting max_output_tokens.
  Bad usage responses fail accurately; provider failures preserve checkpoints.
- Run-local browser inspection cache, asset-content invalidation, unchanged
  independent review and fresh mechanical checks. Failed/remote/large-workspace
  inspections bypass the cache. Browser listeners are removed after inspection;
  separate artifacts receive separate screenshot filenames.
- Windows installer, tested dependency pins, executable integration example,
  repeatable clean-install verifier, optional non-root container configuration.

## Measured efficiency

Five paired component runs, alternating order, same current source and same
deterministic decision callback. Every arm used real Chromium and completed with
valid audit and identical passing mechanical findings. Only preview caching was
toggled. Each task invoked four synthetic model calls; no paid model inference
was used in this experiment.

| Measure | Cache disabled | Cache enabled |
|---|---:|---:|
| Verification browser inspections per task | 2 | 1 |
| Median full task runtime | 2.6796 seconds | 1.8587 seconds |
| Passing tasks | 5/5 | 5/5 |
| Reported synthetic accounting tokens | 120 | 120 |

Median runtime reduction: **30.64% for this component fixture**. Browser inspection
count reduced 50%. These are local verification savings, not a claim of a 30.64%
speed improvement on all real tasks, reduced model billing, or better judgment.

A 2,500-character recent-result sample previously expanded to 4,041 characters
because head and tail overlapped. It now compacts to 2,041 characters. Artifact
review excerpts also avoid overlapping their head/tail portions. This verifies
a concrete context bug fix; it does not measure whole-task token savings.

## Limits of the release claim

Ready for the supported single-owner Windows CLI/Python MVP workflow after
Python, browser and model credentials are configured. Container deployment
still needs an actual build/run check on a Docker host. No cloud deployment or
public publication was attempted.

Arbitrary agents need a decision adapter; trusted callbacks must not execute
unguarded side effects. The worker is not a multi-tenant service or adversarial
code sandbox. Human judgment, factual accuracy and creativity need broader
evaluation. The earlier 30-pair holdout used a different source snapshot and its
confidence/score gates failed: general superiority remains **unproven**.
Consciousness and real feelings remain unsupported.

See [deployment and integration guide](AEON_DEPLOYMENT_AND_INTEGRATION.md) for
install commands, SDK contract, framework layers, grants and operational scope.
